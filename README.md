# Notion Dive Checklist Resetter

Me and my wife dive. Because we're forgetful and chaotic, we maintain a checklist in Notion to make sure we don't forget any gear while preparing a dive.

Because it's cumbersome to reset the checklist every time, and we don't always dive in the same configuration, I made a little Vercel function that can be called as a webhook that will reset the list for us.
